# NZ Interview Coach

**公開URL：https://nz-interview-coach.ge-pr-1022.workers.dev**

ニュージーランドの面接に向けた練習アプリです。
録音した回答をその場で文字起こしし、NZの面接文化に沿った観点で採点・添削し、履歴を残して改善が見えるようにします。

すべて Cloudflare 上で動きます。外部のAIサービスは使いません。

---

## できること

| 機能 | 内容 |
|---|---|
| AI模擬面接 | 質問に対して口頭で回答 → 自動で文字起こし → 5観点で採点し、改善版の回答を提示 |
| 話し方の計測 | 回答の長さ、話す速さ(語/分)、フィラー(um, like 等)の数と比率、一文の長さ |
| 台本の添削 | 用意した回答を貼り付けると、NZらしい自然な言い回しに直し、一文ずつの言い換え候補を提示 |
| 表現・用語ライブラリ | CSM/AM職の専門用語とNZ職場特有の言い回しを収録。練習中に出た用語も自動で蓄積 |
| 進捗ダッシュボード | スコア・話速・フィラー率の推移、分野別の状況、練習の全履歴 |
| 求人票(JD)対応 | 応募先の求人票を貼り付けると、その求人専用の面接質問をAIが生成 |

質問は最初から56問（NZ向け定番集）、用語は67語が入っています。

## 使っている技術

- **Cloudflare Workers** … サイト本体とAPI
- **Workers AI**
  - `@cf/openai/whisper-large-v3-turbo` … 音声の文字起こし
  - `@cf/meta/llama-3.3-70b-instruct-fp8-fast` … 採点・添削・質問生成
- **D1** … 会話履歴・添削記録・用語ライブラリの保存（Oceaniaリージョン）
- **PWA** … スマホのホーム画面に追加してアプリとして使用可能

音声ファイルそのものは保存しません。解析が終わった時点で破棄され、D1には文字起こしテキストと採点結果だけが残ります。

## セットアップ

### 1. 必要なもの

- Node.js 20以上
- Cloudflareアカウント（無料プランで動きます）

### 2. 準備

```bash
npm install
npx wrangler login
```

### 3. データベースを作る

```bash
npm run db:init   # テーブルを作成
npm run db:seed   # 質問56問と用語67語を投入
```

`db:init` は既存のテーブルを削除してから作り直します。履歴が入ったあとに実行しないでください。

### 4. 公開する

```bash
npm run deploy
```

### 5. 合い言葉を設定する

このコマンドを実行すると入力を求められるので、自分だけが知っている合い言葉を入力してください。
入力した文字は画面に表示されず、Cloudflare側に暗号化されて保存されます。

```bash
npm run secret:password
```

セッション署名用のランダムな文字列も必要です。

```bash
npm run secret:session
```

以上でブラウザからアクセスできるようになります。

## スマホでアプリとして使う

1. iPhoneのSafariで公開URLを開く
2. 下部の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選ぶ

Androidの場合はChromeのメニューから「アプリをインストール」を選びます。
ホーム画面のアイコンから開くと、アドレスバーのない全画面のアプリとして動きます。

**録音についての注意**：ブラウザがマイクを使うには `https://` である必要があります。Cloudflareの公開URLは自動的にhttpsなので問題ありません。初回だけマイクの使用許可を求められるので「許可」を選んでください。

## 日々の使い方

1. **記録**タブで前回までの状況を確認する
2. **練習**タブで「ランダムに1問はじめる」を押す（未練習の質問が優先的に出ます）
3. 録音ボタンを押して、60〜120秒を目安に英語で答える
4. 採点結果を読み、「言い換えの候補」で気になった表現を覚える
5. 良い回答ができたら、**台本**タブに清書して保存しておく

応募先が決まったら、**求人**タブに求人票を貼り付けて専用の質問セットを作ってください。

## 費用について

Cloudflareの無料プランに収まる範囲で設計しています。
Workers AI には1日あたりの無料枠があり、1回の練習で消費する量は多くありません。
上限に達した場合は翌日まで待つか、Cloudflareのダッシュボードで有料プラン（月$5から）に切り替えてください。

## ファイル構成

```
src/index.js      APIのルーティング
src/ai.js         Workers AI の呼び出しとプロンプト（採点基準はここ）
src/metrics.js    話す速さ・フィラーなどの計測
src/auth.js       合い言葉による認証
public/           画面（HTML・CSS・JavaScript）
db/schema.sql     テーブル定義
db/seed.sql       質問と用語の初期データ
db/_gen_seed.py   seed.sql を生成するスクリプト
```

質問や用語を追加したいときは `db/_gen_seed.py` を編集し、`python3 db/_gen_seed.py` で再生成してから `npm run db:seed` を実行してください。
採点の基準や言い回しの好みを変えたいときは `src/ai.js` のプロンプトを編集します。
